# 개인 기술 블로그 - 제품 요구사항 명세서 (PRD)

## 1. 핵심 정보

### 프로젝트명
개인 기술 블로그

### 프로젝트 목적
Notion을 CMS로 활용한 개인 기술 블로그 플랫폼 구축 — Notion에서 작성한 글이 자동으로 블로그에 반영되는 시스템 제공

### 타겟 사용자
기술 블로그를 운영하는 개발자 (인증 불필요)

---

## 2. 사용자 여정 (User Journey)

```
홈 페이지
  ├─ 검색 바 입력 → 검색 결과 페이지
  ├─ 카테고리 선택 → 카테고리 페이지
  └─ 글 제목 클릭 → 글 상세 페이지
      ├─ 이전/다음 글 네비게이션 → 다른 글 상세 페이지
      ├─ 관련 글 클릭 → 글 상세 페이지
      └─ 카테고리/태그 클릭 → 필터링된 글 목록 페이지
```

---

## 3. 기능 명세 (Features)

| 기능 ID | 기능명 | 설명 | 관련 페이지 |
|---------|--------|------|-----------|
| **F001** | 글 목록 조회 | Notion 데이터베이스에서 발행 상태의 글 목록을 시간순(최신순)으로 조회 | 홈, 검색 결과, 카테고리 |
| **F002** | 글 상세 표시 | 개별 글의 제목, 메타데이터(발행일, 카테고리, 태그), 본문 내용 표시 | 글 상세 |
| **F003** | 카테고리별 필터링 | 사용자가 선택한 카테고리로 글 목록 필터링 | 홈, 카테고리 |
| **F004** | 검색 기능 | 제목 또는 태그로 글 검색 (키워드 매칭) | 홈, 검색 결과 |
| **F005** | 반응형 디자인 | 모바일(320px), 태블릿(768px), 데스크톱(1024px) 모두 최적화 | 모든 페이지 |

## 5. 페이지별 상세 기능 (Page Specifications)

### 5.1 홈 페이지 (/)

**구현 기능:** `F001`, `F003`, `F004`, `F005`

| 항목 | 내용 |
|------|------|
| **역할** | 블로그의 진입점, 최근 글 목록과 주요 기능 제공 |
| **진입 경로** | 로고 클릭, 브라우저 홈 페이지 |
| **사용자 행동** | 1. 카테고리 선택 → 카테고리 페이지 이동 (F003)<br>2. 글 제목 클릭 → 글 상세 페이지 이동 (F002)<br>3. 검색 바에 입력 → 검색 결과 페이지 이동 (F004) |
| **주요 기능** | • 헤더 (네비게이션, 검색 바)<br>• 히어로 섹션 (블로그 소개)<br>• 카테고리 필터 바 (F003) - 모든 카테고리, 개별 카테고리<br>• 글 목록 카드 (F001) - 제목, 발행일, 카테고리, 미리보기 텍스트<br>• 페이지네이션 또는 무한 스크롤<br>• 검색 바 (F004)<br>• 반응형 디자인 (F005)<br>• 푸터 |
| **다음 이동** | 글 상세, 카테고리, 검색 결과 |

### 5.2 글 상세 페이지 (/blog/[slug])

**구현 기능:** `F002`, `F003`, `F004`, `F005`

| 항목 | 내용 |
|------|------|
| **역할** | 개별 글의 전체 내용과 메타데이터 표시 |

| **사용자 행동** | 1. 카테고리 클릭 → 카테고리 페이지 이동 (F003)<br>2. 태그 클릭 → 검색 결과 페이지 이동 (F004)<br>3. 관련 글 클릭 → 다른 글 상세 페이지 이동 (F002)<br>4. 이전/다음 버튼 클릭 → 인접한 글로 이동 |
| **주요 기능** | • 글 메타데이터 (제목, 발행일, 카테고리, 태그)<br>• 글 본문 (Notion 블록 변환, 마크다운 포맷, 코드 구문 강조)<br>• 관련 글 섹션 (같은 카테고리 최근 3-5개)<br>• 이전/다음 글 네비게이션<br>• 반응형 디자인 (F005)<br>• 목차 (사이드바, 선택사항) |

### 5.3 카테고리 페이지 (/category/[categoryName])

**구현 기능:** `F001`, `F003`, `F005`

| 항목 | 내용 |
|------|------|
| **역할** | 특정 카테고리에 속한 글 목록 표시 |
| **진입 경로** | 홈에서 카테고리 선택, 글 상세에서 카테고리 클릭, 네비게이션 드롭다운에서 선택 |
| **사용자 행동** | 1. 글 제목 클릭 → 글 상세 페이지 이동 (F002)<br>2. 다른 카테고리 선택 → 해당 카테고리 페이지 전환 (F003)<br>3. "모든 카테고리" 클릭 → 홈 이동 |
| **주요 기능** | • 카테고리 제목 + 글 개수 표시<br>• 글 목록 (F001, F003) - 카테고리 필터링, 최신순 정렬<br>• 카테고리 네비게이션 (모든 카테고리, 현재 카테고리 강조)<br>• 글 카드 (제목, 발행일, 미리보기)<br>• 페이지네이션<br>• 반응형 디자인 (F005) |
| **다음 이동** | 글 상세, 홈, 다른 카테고리 |

### 5.4 검색 결과 페이지 (/search?q=[keyword])

**구현 기능:** `F001`, `F004`, `F005`

| 항목 | 내용 |
|------|------|
| **역할** | 검색 키워드에 맞는 글 목록 표시 |
| **진입 경로** | 모든 페이지의 검색 바에서 검색 수행 |
| **사용자 행동** | 1. 글 제목 클릭 → 글 상세 페이지 이동 (F002)<br>2. 검색 바 재입력 → 새 검색 수행 (F004)<br>3. "홈으로" 클릭 → 홈 이동 |
| **주요 기능** | • 검색 쿼리 표시 ("결과: '[검색어]' (N개 항목)")<br>• 검색 결과 목록 (F004) - 제목 하이라이트, 발행일, 카테고리, 미리보기<br>• 결과 없음 상태 처리 ("검색 결과가 없습니다")<br>• 글 목록 (F001)<br>• 페이지네이션 (결과 많을 경우)<br>• 반응형 디자인 (F005) |
| **다음 이동** | 글 상세, 홈 |

## 6. 데이터 모델 (Data Model)

### 6.1 Notion 데이터베이스 스키마

| 필드명 (DB 컬럼) | 데이터 타입 | 필수 | 설명 | 사용 기능 |
|------------------|-----------|------|------|----------|
| **Title** | Title | ✓ | 글의 제목 | F001, F002, F004 |
| **Slug** | Text (Unique) | ✓ | URL-friendly identifier (예: my-first-post) | F002 (라우팅) |
| **Category** | Select | ✓ | 단일 카테고리 선택 (예: React, Node.js, DevOps) | F001, F003 |
| **Tags** | Multi-Select | ○ | 복수 태그 (예: hooks, performance, tutorial) | F002, F004 |
| **Published** | Date | ✓ | 발행일 | F001 (정렬), F002 |
| **Updated** | Date | ○ | 수정일 | F002 |
| **Status** | Select | ✓ | 상태: Draft, Published (Published만 노출) | F001 필터 |
| **Content** | Page Content | ✓ | 글의 본문 (Notion 블록) | F002 |
| **Description** | Text | ○ | 미리보기 텍스트 (100자 이상 권장) | F001 |

## 11. 주요 기술 고려사항

### 11.1 Notion API 통합
- **인증**: Internal Integration 토큰 사용 (환경 변수)
- **레이트 제한**: 3req/sec (배치 작업 시 주의)
- **데이터 캐싱**: ISR 또는 On-Demand Revalidation 활용 (최대 1시간)
- **블록 변환**: Notion 블록 → React 컴포넌트 (remark/rehype 또는 커스텀)

### 11.2 성능 최적화
- **정적 생성**: `generateStaticParams()` 활용 (Pre-rendering)
- **이미지 최적화**: Next.js Image 컴포넌트
- **코드 분할**: 동적 import로 번들 크기 감소
- **캐싱 전략**: Vercel 엣지 캐싱

### 11.3 SEO
- **메타 태그**: generateMetadata() 활용
- **Open Graph**: 글 공유 시 미리보기 생성
- **Sitemap**: 동적 XML 사이트맵 생성
- **구조화된 데이터**: Schema.org (BlogPosting)
